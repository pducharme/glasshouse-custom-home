# LG 43NU800BPSC (2026 — webOS 11)

Hardware profile gathered from root shell access on an LG 43NU800BPSC, an
entry-level 4K LCD TV sold in Central America and the Caribbean, running
webOS 11.0.0 (LG's webOS 26). Reported in
[#568](https://github.com/rorygallagher2024/glasshouse/issues/568).

It is the first profiled TV on a Realtek SoC with a PowerVR GPU: every other
profile here is LG silicon with a Mali GPU.

## Storage

| Detail | Value |
|---|---|
| **Type** | eMMC, 8 GB |
| **Device** | S03111 |
| **Health (life_time)** | `0x01 0x01` (0–10% used) |
| **App store partition** | `/dev/mmcblk0p60` — 904 MB (`/mnt/lg/appstore`, `/media`) |
| **Common data** | `/dev/mmcblk0p59` — 721 MB (`/mnt/lg/cmn_data`, `/var`, `/home`) |
| **Database** | `/dev/mmcblk0p57` — 100 MB (`/var/db`) |
| **Root filesystem** | 1.6 GB, full |

The TV ships with store-mode demo videos taking over 600 MB of the 904 MB app
store partition, which leaves almost no room to install apps until they are
removed.
