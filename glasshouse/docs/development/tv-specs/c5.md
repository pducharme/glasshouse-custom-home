# LG OLED48C5PUA (2025 — webOS 10)

Hardware profile and low-level diagnostic data gathered from root shell access on an LG OLED48C5PUA running webOS 10.3.1 (LG's webOS 25).

---

## System Overview

| Detail | Value |
|---|---|
| **Model** | OLED48C5PUA.DUSQDJR (board type `O22N3_ATSC_US`, OTA id `HE_DTV_W25G_AFABATAA`) |
| **Firmware** | 33.31.69 |
| **webOS** | 10.3.1-3007 (codename `ponytail-papikonda`, platform code `10`), image `lib32-starfish-global-secured` |
| **Kernel** | Linux 5.4.268-329.ptl4tv.5 (aarch64, SMP PREEMPT) |
| **Userspace** | 32-bit ARM (`/bin/sh`, `node` and `WebAppMgr` are ELF32) |
| **SoC** | LG1213 / "O22" — Alpha 9 Gen 8 (AArch64) |
| **Chip ID** | `O22A3` (from boot cmdline) |
| **Rooted with** | slopbro |

The C5 is the same LG1213 / O22 silicon as the [C2](c2.md) (chip `O22A2`
there, `O22A3` here), with the same CPU, GPU and kernel line; what moved on is
the firmware, Node and Chromium.

## LG1213 "O22" platform parameters

Same parameter set as the [C2](c2.md), with one difference in the AVS mode:

| Parameter | C5 | C2 |
|---|---|---|
| `o22_cpuNP` / `o22_cpuHS` | 0 / 0 | 0 / 0 |
| `o22_gpuNP` / `o22_gpuHS` | 0 / 0 | 0 / 0 |
| `o22_cpu_avs` | 1 | 2 |
| `o22_core_avs` | 2 | 2 |
| `o22_pms_enable` | 1 | 1 |
| `o22_pms_tfreq` | 0 | 0 |
| `o22_regul` | 1 | 1 |
| `cpu_alp_mode` | 0 | 0 |
| `ddr_alp_mode` | 1 | 1 |

The C2 page's warning about these knobs applies unchanged.
