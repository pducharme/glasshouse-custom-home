# LG 55UA73006LA (2025 — webOS 10)

Hardware profile and low-level diagnostic data gathered from a root shell on an
LG 55UA73006LA, a 55-inch 4K LCD sold in Latin America, running webOS 10.3.1
(LG's webOS 25).

It sits on the same Realtek K25 silicon as the [NU80](nu80.md); what differs is
the model, the browser region (a DVB board rather than ATSC) and the Wi-Fi part.

| **Panel** | 55-inch 4K LCD @ 60 Hz, CSOT (panel module `CSOT_CSPI`, tool type `JDM_TCL`) |

## GPU

| Detail | Value |
|---|---|
| **GPU** | PowerVR Rogue — device name `rgx_merlin9`, BVNC `46.72.102.389` (connection device ID `0:128`) |
| **DDK / firmware** | Rogue DDK 24.1 @ 6525005 (`merlin9_linux`) |
| **Driver** | `pvrsrvkm`, plus Realtek `rtkgpu` glue (kernel log reports `GPU version UM:KM=1717:1717`) |
| **Clock control** | Not exposed via sysfs or debugfs |

The PowerVR core is shared with the [NU80](nu80.md), but the driver reports no
core name or clock interface on this firmware; the name above comes from
`/sys/kernel/debug/pvr/version`.
