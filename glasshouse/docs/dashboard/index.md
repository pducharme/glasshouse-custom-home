# The dashboard

Each of these has a tab of its own in the dashboard, and a deep link to it. OLED Care appears on OLED TVs only.

On a wide screen the tabs are listed down the left. On a phone, or wherever Preferences is set to hide the sidebar, they open from the menu button at the top of the page. In the Android app that button is in the app's bottom bar, beside its back button.

* [Control](control.md): the remote, inputs, volume, playback, picture presets and screen blanking
* [Metrics](metrics.md): temperatures, load, memory, network and HDMI
* [Apps](apps.md): install, uninstall, background services and the home screen
* [Home](home.md): Glasshouse Home, a home screen in place of LG's (experimental, webOS 9)
* [Privacy](privacy.md): screen recognition, ad tracking, data agreements and the blocker
* [OLED Care](oled-care.md): panel wear and the burn-in protections
* [Game](game.md): frame rate and the Game Optimizer
* [Screen savers](screen-savers.md): replacements for LG's
* [Advanced Controls](advanced.md): power and standby, sound routing, HDMI, auto device detection and front lights
* [Service menu](service-menu.md): LG's engineering menu
* [Server](server.md): updates, server settings and the home screen app
* [Tools](tools.md): live webOS system logs, Glasshouse activity and kernel ring buffer diagnostics

For companion applications, see [Glasshouse apps](../apps/tv-app.md), including [The TV app](../apps/tv-app.md) on the TV's home screen and [Glasshouse for Android](../apps/android.md).

The page works with no internet access, and has a dark/light mode toggle (via the UI or `/?theme=light`).

Use the search button at the top of the sidebar (or press `/` or `Ctrl`/`Cmd` + `K`)
to find sections, settings, controls, and installed apps. Useful destinations can be pinned
with the star beside a search result, keeping shortcuts to them in the sidebar.
